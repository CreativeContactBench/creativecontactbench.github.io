# Public reproduction videos

This directory contains the researcher-approved public CreativeContactBench reproduction gallery:

- `index.html` renders the task gallery.
- `task.html` renders the four canonical strategy slots for a task.
- `tasks.js` is the public gallery manifest.
- `optimized/` contains web-ready H.264 MP4 assets.
- `posters/` contains gallery thumbnails.

These public demonstration assets are separate from the password-gated Human Evaluation package. Do not copy
Supabase credentials, participant data, private study manifests, or private storage assets into this directory.
